# 快速部署到另一台 Windows 电脑

## 推荐方式：便携版或安装包

构建便携版：

```powershell
cd services-backend
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\build-portable.ps1
```

生成后复制整个目录：

```text
dist\TVCaptionerBackend
```

在目标电脑上双击：

```text
TVCaptionerBackend.exe
```

这个便携目录已经内置 Python 运行时、后端依赖、`llama_cpp` 和 GGUF 运行库 DLL。打开网页后，按提示准备 ASR 模型和 GGUF 翻译模型即可。

## 开发/测试用：源码目录

把整个 `services-backend` 目录复制到另一台电脑。

第一次双击：

```text
首次安装并启动.bat
```

以后双击：

```text
启动后端.bat
```

浏览器打开：

```text
http://127.0.0.1:8765
```

## 环境监测

网页会按功能分开显示：

- `转写` 标签页：检查当前选择的 ASR / 转写模型。
- `翻译` 标签页：检查是否已经放置可用的 GGUF 翻译模型文件，以及 GGUF 运行库是否可用。

后端服务本身不再作为检查项；页面能打开、接口能返回状态，就说明后端已经起来了。

## 下载策略

后端不会自动下载模型。所有模型按钮都只是打开网页，你手动下载并放到指定目录。

不需要 FFmpeg，也不需要 Ollama。

便携版或安装包会内置 `llama-cpp-python`；网页里的 `GGUF 运行库` 显示可用即可。

页面分成两个标签：

- `转写`：ASR 模型和本地转写测试
- `翻译`：Qwen GGUF 翻译模型列表、自定义 `.gguf` 模型、转写 + 翻译测试
