# 怎么使用这个后端

## 启动

双击：

```text
TVCaptionerBackend.exe
```

打开：

```text
http://127.0.0.1:8765
```

如果你拿到的是源码目录，不是便携版，第一次运行才需要双击 `首次安装并启动.bat`；以后再双击 `启动后端.bat`。

## ASR 模型

ASR 模型自己下载，网页只负责打开模型页面。

模型放置目录：

```text
models\asr
```

比如 `large-v2` 应该放到：

```text
models\asr\large-v2
```

也可以在网页里添加自定义模型目录。校验通过后，它会出现在 ASR 模型下拉框里。

注意：当前直接支持 faster-whisper / CTranslate2 模型目录，暂不支持 whisper.cpp 的单文件 `.bin` 或 `.gguf`。

## 翻译模型

不使用 Ollama。程序会用内置的 GGUF 运行库直接加载模型，目标就是像 PotPlayer 调 `whisper.cpp` 一样：下载模型文件后，程序直接加载使用。

你不需要安装 Python，也不需要安装 `llama-cpp-python`。如果网页状态里 `GGUF 运行库` 是可用的，就说明运行库已经在程序里了。

网页“翻译”标签页会列出 Qwen GGUF 模型。下载 `.gguf` 后放到对应目录，例如：

```text
models\translate\qwen2.5-3b-instruct-gguf
```

也可以在“翻译”标签页添加自定义翻译模型：

- 如果你手里就是一个 `.gguf` 文件，直接填这个文件路径。
- 如果你有一个模型文件夹，填文件夹路径，里面需要至少有一个 `.gguf` 文件。
- 点“校验路径”后，页面会告诉你能不能识别到模型文件。

## 翻译测试

在“翻译”标签页底部填媒体文件或本机路径，选择 ASR 模型和翻译模型，点“开始翻译测试”。

完成后任务队列会出现这些输出：

- `sourceSrt`：原文字幕
- `translatedSrt`：翻译字幕
- `bilingualSrt`：双语字幕
- `json`：完整结果

## 日志

网页里有“日志”标签页，可以筛选 `info`、`warning`、`error`。它会记录接口调用、收到音频、转写原文、翻译后的中文和失败原因。日志自动保留最近 10 天。

## 直播音频

后端只接收前端传来的音频片段。前端负责：

- 从直播或电视端拿音频
- 切成小片段
- 发送到后端

后端接口：

```text
POST /api/live/sessions
POST /api/live/sessions/{sessionId}/chunks
```

片段保存位置：

```text
data\live_audio
```

如果安卓端要直接“发一段音频并等待字幕结果”，优先用：

```text
POST /api/audio/translate
```

用 `multipart/form-data` 发送 `file`、`source_language`、`target_language`。短片段适合这个同步接口；长音频建议用“翻译测试”的异步任务接口。
