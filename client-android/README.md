# TV Captioner Android 客户端

第一版功能：

- 设置 Windows 后端地址和端口。
- 从后端获取已就绪的转写模型和翻译模型，并在每次请求时带上模型名称。
- 选择源语言，默认自动检测。
- 选择目标语言，默认简体中文。
- 启动系统悬浮窗，最多显示 3 行字幕。
- 在设置页预览字幕样式，调节字体大小、文字背景颜色、背景透明度。
- 在字幕显示区域里用遥控器方向键调整字幕位置。
- 使用麦克风录制短音频分片，调用后端 `POST /api/audio/translate`，显示返回的 `translatedText`。

## 构建

```powershell
.\gradlew.bat assembleDebug
```

调试包位置：

```text
app\build\outputs\apk\debug\app-debug.apk
```

## 使用

1. Windows 后端默认端口是 `8765`。
2. 手机和 Windows 主机需要在同一个局域网。
3. App 里的地址请填 Windows 主机的局域网 IP，不要填 `127.0.0.1`。
4. Android 首次启动悬浮字幕时，需要授予麦克风、通知和“显示在其他应用上层”权限。
5. 设置页里选中“字幕显示区域”预览框后，用遥控器方向键移动示例字幕；手机也可以直接在预览区域里按住拖动字幕位置。
6. 保存后再点“开始悬浮字幕”即可按最新位置显示。

如果后端仍只监听 `127.0.0.1`，真机无法从局域网访问；需要让后端监听 `0.0.0.0` 或可访问的局域网地址。

当前客户端使用麦克风采集环境声音。后续如果要直接抓手机/电视系统内声音，需要接 Android MediaProjection 授权流程。
