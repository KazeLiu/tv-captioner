# TV Captioner Android 客户端

## 功能

- 设置 Windows 后端地址和端口。
- 从后端获取已就绪的转写模型和翻译模型，并在每次请求时带上模型名称。
- 在页面上切换麦克风或系统播放声音；系统播放声音需要 Android 10+ 的屏幕/音频采集授权。
- 顶部显示权限列表、用途和当前授权情况，可快速跳转获取或管理权限。
- 选择源语言，默认自动检测。
- 选择目标语言，默认简体中文。
- 启动系统悬浮窗，最多显示 3 行字幕。
- 在设置页预览字幕样式，调节字体大小、文字背景颜色、背景透明度。
- 在字幕显示区域里用遥控器方向键调整字幕位置。
- 录制短音频分片，调用后端 `POST /api/audio/translate`，显示返回的 `translatedText`。

## 构建

```powershell
.\gradlew.bat assembleDebug
```

调试包位置：

```text
app\build\outputs\apk\debug\app-debug.apk
```

## 使用

1. Windows 后端默认端口是 `8765`。
2. 手机和 Windows 主机需要在同一个局域网。
3. App 里的地址请填 Windows 主机的局域网 IP，不要填 `127.0.0.1`。
4. Android 首次启动悬浮字幕时，需要授予音频录制、通知和“显示在其他应用上层”权限。
5. 设置页里选中“字幕显示区域”预览框后，用遥控器方向键移动示例字幕；手机也可以直接在预览区域里按住拖动字幕位置。
6. 保存后再点“开始悬浮字幕”即可按最新位置显示。
7. 如果选择“系统播放声音”，启动前还需要在系统弹窗里允许采集；受 Android 和播放 App 限制，部分 DRM/受保护内容可能无法采集到声音。

如果后端仍只监听 `127.0.0.1`，真机无法从局域网访问；需要让后端监听 `0.0.0.0` 或可访问的局域网地址。

系统声音采集使用 Android MediaProjection + AudioPlaybackCapture。Android 10 以下只能使用麦克风模式。
